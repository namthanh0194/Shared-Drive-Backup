Kết nối & nơi lưu

Chọn đúng bộ nhớ, duyệt thư mục rồi xác nhận nơi lưu.

1. Xác thực Google (Service Account)

Chưa nhập credentials.

Dùng file JSON service_account tải từ Google Cloud Console. Nhớ thêm email của Service Account này vào thành viên Bộ nhớ dùng chung (quyền Quản lý nội dung hoặc Người chỉnh sửa).

Không hiển thị hoặc gửi file lên GitHub.

Lưu ý: Bạn đang truy cập panel qua HTTP. Để bảo mật cao nhất, bạn cũng có thể nhập file trực tiếp qua SSH nếu muốn.
📖 Hướng dẫn từng bước lấy file JSON Service Account (5 phút)
  1. Truy cập Google Cloud Console: console.cloud.google.com (đăng nhập tài khoản Google).
  2. Tạo một Project mới (hoặc chọn project đã có sẵn).
  3. Bật Google Drive API: Vào menu tìm kiếm gõ Google Drive API → bấm Enable (Bật).
  4. Tạo Service Account: Vào IAM & Admin → Service Accounts → bấm + CREATE SERVICE ACCOUNT: Nhập tên (vd: aapanel-backup) → bấm Create and Continue → Done.
  5. Tải khóa JSON: Bấm vào Service Account vừa tạo → chuyển qua tab KEYS → bấm ADD KEY → Create new key → chọn định dạng JSON → bấm Create để tải file về máy.
  6. Cực kỳ quan trọng: Copy địa chỉ email của Service Account đó (dạng ...iam.gserviceaccount.com) → Mở Google Drive trên web → Chuột phải vào Bộ nhớ dùng chung bạn muốn lưu → Chọn Quản lý thành viên (Manage members) → Dán email vào và cấp quyền Người chỉnh sửa (Editor) hoặc Người quản lý nội dung (Content manager).
Hoặc nhập file qua lệnh SSH
/www/server/panel/pyenv/bin/python \
  /www/server/panel/plugin/shared_drive_backup/cli.py \
  import-credentials /duong-dan-an-toan/credentials.json

File phải do bạn cung cấp. Plugin không đọc lại credentials của plugin Google Drive cũ.
