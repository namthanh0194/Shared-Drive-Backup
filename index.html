Không có lịch chạy ngầm riêng. Backup định kỳ được quản lý trong Cron Job aaPanel. Bản cũ trên Drive chỉ được dọn sau khi bản mới đã xác minh và bạn đã bật quyền dọn.

Kết nối & nơi lưu

Chọn đúng bộ nhớ, duyệt thư mục rồi xác nhận nơi lưu.

1. Xác thực Google (Service Account)

Chưa nhập credentials.

Dùng file JSON service_account tải từ Google Cloud Console. Nhớ thêm email của Service Account này vào thành viên Bộ nhớ dùng chung (quyền Quản lý nội dung hoặc Người chỉnh sửa).

Không hiển thị hoặc gửi file lên GitHub.

Lưu ý: Bạn đang truy cập panel qua HTTP. Để bảo mật cao nhất, bạn cũng có thể nhập file trực tiếp qua SSH nếu muốn.
📖 Hướng dẫn từng bước lấy file JSON Service Account (5 phút)
  1. Truy cập Google Cloud Console: console.cloud.google.com (đăng nhập tài khoản Google).
  2. Tạo một Project mới (hoặc chọn project đã có sẵn).
  3. Bật Google Drive API: Vào menu tìm kiếm gõ Google Drive API → bấm Enable (Bật).
  4. Tạo Service Account: Vào IAM & Admin → Service Accounts → bấm + CREATE SERVICE ACCOUNT: Nhập tên (vd: aapanel-backup) → bấm Create and Continue → Done.
  5. Tải khóa JSON: Bấm vào Service Account vừa tạo → chuyển qua tab KEYS → bấm ADD KEY → Create new key → chọn định dạng JSON → bấm Create để tải file về máy.
  6. Cực kỳ quan trọng: Copy địa chỉ email của Service Account đó (dạng ...iam.gserviceaccount.com) → Mở Google Drive trên web → Chuột phải vào Bộ nhớ dùng chung bạn muốn lưu → Chọn Quản lý thành viên (Manage members) → Dán email vào và cấp quyền Người chỉnh sửa (Editor) hoặc Người quản lý nội dung (Content manager).
Hoặc nhập file qua lệnh SSH
/www/server/panel/pyenv/bin/python \
  /www/server/panel/plugin/shared_drive_backup/cli.py \
  import-credentials /duong-dan-an-toan/credentials.json

File phải do bạn cung cấp. Plugin không đọc lại credentials của plugin Google Drive cũ.

Khôi phục từ Shared Drive

Chọn đúng website aaPanel và bản backup đã xác minh của VPS này.

Mặc định an toàn: Giải nén kiểm tra. File được tải và giải nén vào thư mục riêng, chưa thay đổi website. Khôi phục website sẽ thay thế toàn bộ file tại webroot, giữ snapshot và thư mục cũ; không khôi phục MySQL, OLS, SSL hay DNS. Cần dừng website và các tác vụ ghi dữ liệu trước khi thay thế. Backup có exclusions chỉ được giải nén kiểm tra.

Chưa chọn website.

Danh sách lấy từ lịch sử đã xác minh của plugin, không quét backup của VPS khác. Bản cũ cần xác nhận liên kết website trước khi khôi phục. Đồng bộ dùng bảng backup của core aaPanel: bản remote mở cài đặt plugin để khôi phục, không giả thành bản local. Danh sách native phản ánh lần đồng bộ gần nhất; xoá dòng native không xoá file trên Drive.

Backup & khôi phục MySQL

Database ứng dụng local do aaPanel quản lý. Không gồm database hệ thống, tài khoản/quyền MySQL hoặc máy chủ từ xa.

Khôi phục file/code website không khôi phục MySQL. Mỗi database được backup riêng; một đợt không bảo đảm snapshot đồng thời giữa các database. Không đổi tên database khi restore.

Đồng bộ các bản MySQL đã xác minh trong lịch sử plugin vào cột Backup ở Databases của aaPanel. Không tính vào backup mã nguồn Website; tải và khôi phục bản trên Drive tại plugin này.

1. Xác nhận website sử dụng database nào

Không suy đoán bằng tên hoặc đọc mật khẩu website. Một website có thể dùng nhiều database; database dùng chung sẽ ảnh hưởng mọi website liên quan.

Bỏ chọn tất cả để xóa liên kết của website đang chọn, không xóa database.

2. Backup database theo đợt

Mỗi database có file .sql.gz và checksum riêng. Đợt hoàn tất có manifest trên Drive; đợt lỗi hiển thị rõ các mục đã thành công.

Chỉ dọn khi đã bật dọn Drive; giữ các file còn được đợt backup tham chiếu.

3. Khôi phục database từ Drive

Chọn một đợt hoặc backup database cũ. Worker kiểm tra ownership/checksum và tạo snapshot local của tất cả database đích trước khi import bất kỳ database nào.

Chưa chọn database.

Import xóa và tạo lại database đích để loại bỏ cả bảng phát sinh sau bản backup; không sửa tài khoản/quyền MySQL. Khi một mục lỗi, cả đợt dừng; không tự rollback các mục đã chạy. Snapshot và journal được giữ để quản trị viên phục hồi rõ ràng.

100 tác vụ gần nhất. Tải lại vào thư mục kiểm tra, không ghi đè production.
