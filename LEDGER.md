## 2026-10-27 — DEV-only modal regression investigation

- Approved scope: reproduce the recurring bottom clipping and clipped close button, fix only DEV, and verify long tabs, resizing and themes. No production install, cache mutation, version bump, commit, push or release in this iteration.
- Reproduced using the installed aaPanel jQuery 1.10.2, layer.js/layer.css, the actual legacy `set_lib_config` opener and software.html message bridge inside a bounded fixture iframe. APIs, history and outer panel shell are test fixtures; this is not a logged-in live browser session or a Google backup.
- Proven root cause: the plugin script executes while jQuery inserts layer content, before layer finishes its synchronous `.auto().offset().callback()` initialization. Layer subsequently writes `top:20%` through jQuery, replacing the previous inline `top:20px !important`; more CSS priority does not fix this ordering. At an iframe height of 870px, unchanged HEAD placed the popup at 174px with its bottom at 1004px. The original close2 target extended above/right of the popup and could be clipped by its overflow.
- Regression evidence: `MODAL_BASELINE=1` runs the same test against unchanged HEAD and fails the viewport containment assertion. Baseline screenshot/geometry and test log are in ignored tmp/modal-baseline.png, tmp/modal-baseline.json and tmp/modal-baseline-run.log.
- Fix: coalesce layout with requestAnimationFrame so it runs after layer initialization and resize callbacks; use an owned sdb-modal class, flex title/content and one scroll container instead of competing hardcoded content heights and layer.style calls. Keep the existing close handler but place the entire labelled close target inside the title bar. Propagate root theme variables to this modal only, including manual theme toggles.
- Fixed geometry in the same fixture: top 20px, bottom 850px inside the 870px iframe; close target top 25px/bottom 55px inside the 40px title. No mandatory minimum viewport height/width that would overflow short/narrow screens remains.
